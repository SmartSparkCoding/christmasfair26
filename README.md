# Ashford School Christmas Fair 2026

A complete, polished website and digital programme for the Ashford School Christmas Fair 2026, held on Saturday 29th November 2026 from 12:00 pm - 4:00 pm at the Great Chart Site.

## About

This website provides:
- **Homepage** - Event overview, highlights, and welcome message
- **Digital Programme** - Full schedule of performances, attractions, and activities with filtering
- **Stall Directory** - Browse all stalls with search functionality
- **Visitor Information** - Essential details for visitors including locations, safety, and contact info
- **Raffle** - Information about super and everyday raffles with all prizes

## Features

- **Modern Christmas Classic Design** - Warm, festive aesthetic using Ashford School's colours (navy, burgundy) with traditional Christmas accents
- **Responsive Design** - Mobile-first, works beautifully on all devices
- **Interactive Programme** - Filter by category, print-friendly
- **Searchable Stall Directory** - Find stalls quickly
- **Accessible** - Semantic HTML, keyboard navigation, reduced motion support
- **Print-Friendly** - Programme can be printed directly from the browser

## Tech Stack

- [Astro](https://astro.build/) - Static Site Generator
- TypeScript - Type safety
- CSS Custom Properties - Design system
- Google Fonts (Cormorant Garamond, Inter)

## Development

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
